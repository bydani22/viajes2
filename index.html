05

Publicarlo en GitHub Pages

  1. Crea un repositorio llamado, por ejemplo, viajes.
  2. Sube index.html, style.css y script.js de este generador a la raíz.
  3. Para cada viaje, descomprime el ZIP dentro de una carpeta con su slug.
  4. Activa GitHub Pages desde Settings → Pages, usando la rama main.
  5. Tu viaje quedará en https://TUUSUARIO.github.io/viajes/SLUG/.
  6. Esa URL es la que puedes grabar en tu etiqueta NFC.
